# Backlog roulette

Too many games, nothing to play? Open **My Library** and click **Pick a game**
(the dice button on mobile) to draw tonight's quest.

The dialog shows the chosen game's cover, status, genres and platforms. Use:

- **Roll again** to draw another game. With multiple candidates, consecutive
  draws never repeat the same game.
- **View game** to open its existing game details, journal and other actions.
- **Start playing** to move an owned game to Playing. The change is saved to
  your collection, and the game appears on the Playing page.

## Choose your pool

**Pick from** defaults to **Owned games**. You can also choose **Currently
playing** to continue a game, or **All visible games** to draw from other
statuses.

Your current Library search and filters apply to every pool, including genre,
platform, rating and status filters. Hidden games are always excluded from the
draw, even when shown in the Library. Account content filters continue to apply.

When no games match, the dialog explains how to change the pool or Library
filters. With one matching game, it shows that game and disables Roll again.
Drawing a game never changes your collection; only Start playing changes status.

No API key, command line or additional setup is needed. The feature uses the
Library's existing authenticated data and status update endpoint.
